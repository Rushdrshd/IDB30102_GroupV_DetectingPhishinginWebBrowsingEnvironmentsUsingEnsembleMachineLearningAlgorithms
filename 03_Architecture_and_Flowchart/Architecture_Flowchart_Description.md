# Proposed System Architecture and Flowchart

## Proposed System Architecture

The proposed system architecture represents the planned phishing website detection framework using ensemble machine learning algorithms.

The architecture consists of several main components:

1. Research Input and Literature Findings
- Provides the research foundation based on previous studies related to phishing website detection.

2. Phishing and Legitimate Website Dataset Sources
- Provides datasets containing phishing websites and legitimate websites for analysis.

3. Data Collection and Preparation
- Collects and prepares the required website data for further processing.

4. Data Preprocessing Stage
- Performs cleaning, filtering, and transformation to improve data quality.

5. Feature Extraction Stage
- Extracts important website-related features such as URL features, domain features, and website content features.

6. Ensemble Machine Learning Classification Approach
- Applies ensemble machine learning algorithms to classify websites.

7. Expected Classification Outcome
- Produces two possible outcomes:
  - Phishing Website Detection
  - Legitimate Website Detection


## Proposed Flowchart

The proposed flowchart illustrates the research process based on Design Science Research Methodology (DSRM).

The process begins by identifying the phishing website detection problem and research gap. The proposed objectives and detection framework are then defined, followed by determining required data, features, detection approach, and evaluation methods.

The flow continues with evaluation criteria checking and analysis of expected outcomes.
