## Purpose of Reference

The referenced project was reviewed as a technical reference for understanding existing approaches in phishing website detection using machine learning algorithms.

The project provides examples related to:

- Phishing website dataset processing
- Website feature extraction
- Machine learning classification approaches

## Adaptation in This Research

The referenced project is not copied directly into this repository.

The following concepts were adapted for the proposed research:

1. Dataset preprocessing workflow for phishing website detection.

2. Website feature extraction concepts for identifying phishing-related characteristics.

3. Machine learning classification workflow.


The proposed research extends this direction by focusing on an ensemble machine learning approach for detecting phishing websites in web browsing environments.
